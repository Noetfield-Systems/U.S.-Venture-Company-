# U.S. Venture Company — Venture Launch Desk

Public-facing founding-stage U.S. market-entry platform. **Pre-incorporation**: not a filed legal corporation or a guaranteed financing, banking, immigration, tax, or legal service.

Tech stack: Node.js HTTP service, accessible responsive SPA, consent-based founder intake, persistent operator lead queue, and standalone launch/legal/operations documentation.

## Run

`npm start` (requires Node 20+). Set `DATA_DIR` to a persistent Railway volume path and `ADMIN_TOKEN` to a secret before receiving production inquiries. See `docs/` and `AGENTS.md`.

## Operating boundaries

Noetfield Systems Inc. is a separate prospective technical service vendor. The proposed U.S. entity is **not yet incorporated**. No fabricated partner logos, offices, testimonials, transactions, customers, investor endorsements or real-time agent activity.
