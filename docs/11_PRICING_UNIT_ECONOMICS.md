## Contribution example (illustrative only)
$499 sale, filing $154, agent $113, provider $70, support $105, refund reserve $18 = $460 cost → $39 contribution / 7.8%. This example demonstrates that claiming "$499 all-in" before actual vendor quotes is risky. All cost numbers are planning assumptions, not supplier quotes. If state/agent fees are pass-through, calculation must exclude pass-through from contribution revenue and cost correctly.

## Checkout + economics release conditions
Actual contractual seller/entity, costed official fees, service scope, cancellation/refund rules, real merchant payments and verified settlement callback. State filing success recorded from official state/provider evidence. Track renewals and refunds, not vanity MRR.
